Buku Induk Penduduk

Buku Induk Penduduk merupakan buku administrasi yang digunakan untuk mencatat identitas dan informasi dasar penduduk desa secara terstruktur.

Mode Simulasi Antarmuka: Seluruh nama warga, NIK (997406...), dan Nomor KK awal merupakan data contoh fiktif (bukan identitas penduduk sebenarnya) yang disimpan di localStorage peramban.

    Import Data Buku Induk Penduduk (Excel)

    Format Kolom Buku Induk Penduduk (Kode B.1)
    Gunakan berkas template Excel resmi berisi susunan kolom Buku Induk Penduduk beserta contoh data fiktif. Nomor urut pada tabel tetap dibuat otomatis oleh sistem.
    1. Pilih Berkas Excel
    Mendukung format Microsoft Excel (.xlsx, .xls) maupun .csv. Anda juga dapat menyeret berkas ke kotak ini.
    2. Mode Penyimpanan Import
    Tentukan cara penggabungan baris Excel dengan data Buku Induk Penduduk yang sudah ada:
